# Laptop Chip Database

An open, searchable database of laptop processors and graphics chips.

## Development

Open `index.html` directly in a browser, or run:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Scope

The current MVP includes a searchable list of sample laptop CPU and GPU entries. Chip specifications and laptop-specific performance should always include their source and test conditions.
